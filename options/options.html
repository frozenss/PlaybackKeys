AutoHotkey bridge is Windows-only.

Windows: remap with AutoHotkey advanced · optional — map External hotkeys to Commands

Record OS-level External hotkeys for Commands, then download one AHK bridge script. Rows without a Chrome target chord can still be recorded; they are skipped in the script until bound.

Install AutoHotkey v2, download the script, then run it (optionally start with Windows). Keep each Command set to Global in Chrome shortcut settings so SendInput still reaches PlaybackKeys while another app is focused.

Chrome Command chords changed since the last download. Regenerate the AHK bridge script.
Privacy

PlaybackKeys collects nothing. No telemetry, no network requests, no analytics. Settings live in chrome.storage on your device. Source code at github.com/mehmetdemircs/PlaybackKeys.
